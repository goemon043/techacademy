Para los fines de interpretación de este documento, se establecen las siguientes definiciones:

4.1. Datos Proporcionados Voluntariamente:

Al completar los formularios de registro, recopilamos: nombre, apellidos, dirección de correo electrónico, preferencias de cursos y aceptación de políticas. Base legal: Ejecución de un contrato y consentimiento explícito del interesado.

4.2. Datos Recopilados Automáticamente (Telemetría):

Cada vez que interactúa con el Sitio, nuestros servidores y servicios de terceros (como CDNs y analíticas) registran automáticamente:

  • Dirección IP (pública y, en su caso, geolocalización aproximada).

  • Agente de usuario (User-Agent) y capacidades del navegador.
  • URL de referencia (Referrer) y rutas de navegación dentro del Sitio.
  • Timestamps de interacción, profundidad de scroll y eventos de clic (Clickstream data).

Base legal: Interés legítimo del Titular para garantizar la seguridad de la red, prevenir fraudes, optimizar el rendimiento de la infraestructura y realizar análisis estadísticos anonimizados.

  • Cifrado en reposo para bases de datos sensibles utilizando algoritmos AES-256.
  • Protección contra ataques de inyección SQL, Cross-Site Scripting (XSS) y Cross-Site Request Forgery (CSRF) mediante Web Application Firewalls (WAF).
